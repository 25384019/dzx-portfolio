# Chapter 05「裂隙阈值」设计规格

## 目标

将 Chapter 05 的当前双层矩形终点门替换为更克制、更抽象的「裂隙阈值」。右侧视觉应与左侧联系文案形成平衡，传达抵达数字世界边缘、跨越未知边界的终章感，同时保持现有网站安静、精密的空间语言。

## 范围与约束

- 只修改 CONTACT 章节相关实现，主要落点为 `src/scenes/ContactScene.ts`；如响应式排版确有必要，可对 Chapter 05 的局部样式做最小调整。
- 不修改自 commit `b0c96f5` 起冻结的 PROJECTS / XiaoZhaiOS 交互与参数。
- 不修改自 commit `b6ce42c` 起冻结的 INTERESTS 视觉参数。
- `World.ts` 的全局粒子数量保持 `count = 480`。
- CONTACT 继续通过 `particleFactor = 0.035` 获得终章的安静密度。
- 保留 Chapter 05 中文文案：

  > 关于人工智能、软件、数字体验，  
  > 或者一个值得实现的想法。

- 不恢复已永久删除的英文代理服务文案。
- 保留 MediaCard 在 `progress > 4.45` 至 `4.8` 的淡出行为及前四章位置规则。
- 必须支持 reduced-motion，并保持当前低分配更新路径。

## 视觉构图

### 核心符号

右侧主体由两条空间基准组成：

1. 一道极细的纵向光隙，作为不可见之门的抽象边界。
2. 一条轻微透视倾斜、向远端渐隐的地平线，与光隙相交形成视觉原点。

光隙不使用封闭矩形轮廓。它由窄核心、柔和外晕和极淡内部光雾组成，避免普通科幻门户的直白感。交点是视觉能量最集中的位置，但亮度仍低于主标题，确保阅读层级为标题、中文说明、联系按钮、空间符号。

### 色彩与层次

- 主体采用冰湖青与雾蓝，延续全站冷色结构。
- 樱粉仅用于短暂的交点脉冲，与标题强调色建立联系。
- 地平线从近端向远端非线性衰减，末端完全融入背景。
- 局部辉光限制在光隙和交点附近，不使用全屏 bloom。
- 保留页面原有微粒和网点质感，不新增大面积面板或 HUD 装饰。

### 响应式

- 桌面端：阈值位于右侧负空间，交点约处于右侧视觉区域中心略下方。
- 窄桌面和平板：整体向内收缩并减弱横向延伸，避免侵入标题区。
- 移动端：缩短地平线，降低光隙高度；不依赖 hover，使用低频自动微脉冲维持生命感。

## 互动与动效

### 默认状态

光隙进行极慢、低幅度的亮度呼吸。地平线和交点保持稳定，不产生持续位移。章节进入时使用现有滚动进度驱动的平滑显现，不突然闪现。

### 指针感应

- 指针进入阈值附近的软区域后，光隙亮度平滑提升，最大增幅约 12%。
- 交点产生局部聚光，地平线出现一圈低幅、短距离的扩散波。
- 指针移开后使用缓慢阻尼回归默认状态，无突变。
- 指针横穿光隙时触发一次樱粉微脉冲；脉冲设冷却时间，避免来回抖动时连续闪烁。
- 互动仅改变发光和局部波形，不移动主体，不改变页面滚动，不创建可点击语义。

### Reduced Motion

启用 `prefers-reduced-motion` 时冻结呼吸、波纹与自动脉冲。滚动进入仍以现有进度提供必要的状态可见性，但不执行时间驱动运动。

## 工程结构

`ContactScene` 继续保持独立 Three.js 场景对象，由外部世界负责更新和生命周期管理。

- 光隙与局部气氛由单个局部 ShaderMaterial 平面绘制。
- 地平线使用带顶点颜色的 BufferGeometry 实现距离渐隐。
- 交互状态由预分配标量维护，包括平滑后的邻近值、上一次指针侧向位置、脉冲强度和冷却状态。
- `update()` 不创建临时 Three.js 对象或数组。
- 所有 geometry 和 material 在 `dispose()` 中释放。

目标新增开销不超过 3 个 draw call，且不引入新运行时依赖。

## 状态与数据流

1. 外部世界将时间、帧间隔、章节进度和指针到 CONTACT 主体的距离传入 `ContactScene.update()`。
2. 章节进度决定场景可见性与显现强度。
3. 指针距离通过帧率无关的指数阻尼转为邻近强度。
4. 指针相对光隙的左右侧变化触发一次受冷却控制的横穿脉冲。
5. Shader uniforms 接收时间、显现、邻近和脉冲强度，生成局部光隙、交点辉光与扩散波。
6. reduced-motion 覆盖时间驱动状态，使视觉停留在稳定静态构图。

若现有调用方只提供指针距离、无法判定左右穿越，则实现阶段为 CONTACT 增加一个最小的签名扩展以传入指针相对 X；不得修改其他章节的交互语义。

## 验证标准

- `npm run build` 通过。
- 使用 `scratch/verify_contact_gate.cjs` 验证桌面、移动端、时间注入、Reduced Motion 和 AXTree。
- 桌面截图中光隙与地平线清晰可辨，但不比标题更亮。
- 指针靠近时亮度平滑变化；横穿时每次有效穿越只产生一次微脉冲。
- Reduced Motion 下相同章节进度、不同测试时间得到稳定一致的阈值状态。
- 移动端不遮挡标题、中文文案或联系按钮。
- 确认 `World.ts` 中 `count = 480`、CONTACT 的 `particleFactor = 0.035` 均未变化。
- 确认 PROJECTS 与 INTERESTS 的冻结文件无差异。

## 非目标

- 不增加联系表单、音效、点击开门流程或新导航行为。
- 不重写全站排版、配色或粒子系统。
- 不恢复矩形门框，也不新增大型几何体、节点网络或装饰性 HUD。
